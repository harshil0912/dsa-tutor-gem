# DSA Gem 🧠
A personal DSA tutor built on Google Gemini. 
Explains concepts, visualizes data structures, generates 
quizzes/flashcards, and can reference your own textbook PDF.

## Features
- 📖 Topic explanations with examples
- 🎴 Quizzes & Flashcards
- 🖼️ ASCII visualizations
- 💻 Code in Python, C++, Java
- 📄 PDF-aware (upload your textbook)

## How to use
1. Go to gemini.google.com/gems/create
2. Paste the instructions from `instructions.txt`
3. Upload your DSA PDF
4. Start learning!
